# Aplikasi Analisis Risiko Menggunakan Logika Fuzzy

Aplikasi berbasis web untuk menganalisis, mengevaluasi, dan memetakan tingkat risiko secara akurat menggunakan metode _Fuzzy Inference System_. Dibangun menggunakan Python dan Streamlit, serta di-deploy secara otomatis menggunakan Docker di Hugging Face Spaces.

## 🚀 Fitur Utama

- Kalkulasi tingkat risiko secara instan berdasarkan variabel input.
- Implementasi logika Fuzzy untuk akurasi keputusan.
- Antarmuka web yang interaktif dan responsif menggunakan Streamlit.
